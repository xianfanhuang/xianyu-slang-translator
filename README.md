# 闲鱼黑话翻译器

闲鱼平台黑话、暗语、行话结构化词典与 AI Skill 定义，帮助快速解读商品描述、识别卖家真实意图、规避交易风险。

## ✨ 功能特性

- 覆盖 6 大类 100+ 条闲鱼常用黑话与暗语
- 三色风险分级：🟢 正常 | 🟡 留意 | 🔴 高危
- 不仅翻译字面含义，补充解读卖家真实意图与话术水分
- 可直接作为 AI 助手 Skill 导入支持 Skill 机制的平台
- 持续更新新兴黑话与品类暗语

## 📖 词典分类
1. **成色描述类**：99新、伊拉克成色、充新、战损级等
2. **砍价议价类**：小刀、屠龙刀、回血、白菜价、不刀等
3. **交易方式类**：面交、自提、到付、私、走平台、验货宝等
4. **身份暗示类**：女大学生自用、个人卖家、二手贩子识别等
5. **品类谐音类**：数码、奢侈品、球鞋、潮玩、谷圈、烟酒等
6. **高危警示类**：诈骗、违规交易暗语识别与风险提示

## 🚀 使用方式

### 作为 AI Skill
直接将 `SKILL.md` 与 `data/` 目录导入支持 Skill 机制的 AI 平台，即可自动触发黑话翻译能力。

### 本地查询 / 二次开发
直接引用 `data/slang-dictionary.json` 结构化数据，可自由接入自己的应用、机器人、小程序等。
